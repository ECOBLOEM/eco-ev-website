ECO EV LOGO PACK

Mark: a ring with a centre dot.
Wordmark: "ECO EV" in Michroma, letter-spaced. The lettering is converted to shapes, so it looks the same everywhere with no font needed.

COLOURS
Teal (logo):        #1F6B73
Charcoal (text):    #1E2124
Cream (background): #F7F4EF
Light teal (logo on dark backgrounds): #7FC4CB
White

FILES
svg/  Vector files, sharp at any size. Use these for printing, signage, vehicle branding and your designer.
png/  Ready-to-use images with transparent backgrounds (number = width in pixels).

eco-ev-logo            Main logo: teal mark + charcoal text. Use on light backgrounds.
eco-ev-logo-white      All white. Use on dark backgrounds and photos.
eco-ev-logo-reverse    Light teal mark + white text. Use on dark backgrounds.
eco-ev-logo-stacked    Mark above the text. Use for square spaces.
eco-ev-mark            Mark only. Use for small spaces, stickers and watermarks.
eco-ev-icon            Mark on a cream square. Use as the WhatsApp, Facebook or Instagram profile picture.
eco-ev-icon-teal       White mark on a teal square. Alternative profile picture.

RULES
- Keep clear space around the logo of at least the dot's width on every side.
- Don't stretch, rotate, recolour or add effects.
- Smallest size: 16 px for the mark alone, 90 px wide for the full logo.
